## 25問チャレンジの現行仕様
- 登録済み午前Ⅱから重複なし25問を抽選、要復習・未学習優先、習得済みの出題重みを抑える。
- 左に問題一覧、中央に問題文・図・選択肢、右に解答・理解度。狭い画面は縦並び、スマホ固定操作欄あり。
- 既存用語辞書によるホバー・フォーカス・タップ、同一用語IDは設問内初回のみ。選択肢除外、2025年度選択肢並び替え、公式PDF、理解度設定を維持。
- 未回答でも移動可能。前後移動時は選択済みなら採点、番号移動は未確定選択を保持。明示採点は確定済み問題を二重記録しない。通常過去問の再表示時リセットとは区別。
- 未回答は履歴上の誤答として保存せず、結果では分母・再出題対象に含む。全問正解で新しい25問へのボタンを表示。
- セッション内で進行管理。通常の学習履歴に採点結果を保存。ページ更新での途中再開は未対応。
- PR #78: テンプレート空白の表示を除去、問題本文の改行は維持。
- 既存との完全な機能同等性は未達。具体的差分は下記。本書は実装の記録であり、新たな仕様変更の承認ではない。

## 実装照合結果（2026-11-26・静的確認）
- 収録数：午前Ⅱ250問（既存登録記録）、用語70問・辞書197語はコード上の一意ID確認済み。Lv2–5は5業務×各10テンプレート＝各50問。Lv1は用語学習を参照するため二重計上しない。学習問題の合計520問（午後の公式5大問は別）。
- 網羅率＝学習済み一意ID/対象一意ID、定着率＝習得済み一意ID/対象一意ID。午前Ⅱは自己評価または連続2回正解（要復習除外）、用語は連続2回正解、記述は自己評価。0件は0%、小数第1位。7日以上または日付不明の学習済み問題は定着確認対象。ランダム学習は誤答→未学習→未習得→定着確認を優先し、10/20/50問を選択可能。これは記憶定着の実測ではない。
- 25問の抽出重み：要復習・対象誤答14、未学習10、習得済みまたは条件を満たす連続正解0.25、学習中4、その他6（判定順はエンジンに従う）。母集団不足時は25問未満になり得る。
- 参照実装：src/learning-coverage-ui.js、src/am2-25-challenge-engine.mjs、src/am2-25-standalone-ui.js、src/term-understanding-questions.js、src/glossary-terms.js、src/afternoon-step-up-questions.js。
