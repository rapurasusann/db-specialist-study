# DB過去問：午後10年分・PDF先行版（2026-11-24）
 
## 目的と範囲
2027年春の受験準備を優先し、**2016〜2025年度のDB午後Ⅰ・午後Ⅱ（10回×5大問＝50枠）**を早期に選べるようにする。過去問道場の年別・問別の探しやすさを参考にするが、第三者サイトのコード・独自解説・画像は取得・複製しない。**問題冊子と解答例はIPAの公式PDFに直接リンクする。**

既存の2025年度専用学習画面（本文テキスト化・図表・設問選択）・午前Ⅱ・単語理解・用語ツールチップは変更しない。端末間同期/認証の進行中ブランチと区別し、独立ブランチ `feat/pm-archive-ipa-pdf-20261124` で作業する。

## 作成済み
- `src/pm-archive-data.js`：10年度・開催時期・公式年度別ページ・午後Ⅰ／Ⅱ PDFの公式ファイル名を固定データとして登録。2020年度は春期中止のため10月、2016〜2019年度は春期、2021〜2025年度は秋期。
- `src/pm-archive-view.js`：既存ナビの隣に「午後の年度別過去問」を追加。年度・午後Ⅰ/Ⅱ・大問1〜3/1〜2を選択し、IPA公式問題冊子・公式解答例・原本掲載ページへのリンクを表示。各大問に解答入力欄・習熟度選択を用意。
- `index.html`：上記2つをsame-origin scriptとして追加。**既存inline JavaScript、CSP、2025学習画面、既存クラウド同期設定を変更しない。**
- 学習記録は既存の `progress` と `save()` を再利用し、`2018:pm1:2` など従来どおりのキーと `written`、`level`、`seenAnswer` を保存。既存のJSONバックアップ・復元の対象となる。
- `tests/pm-archive.test.mjs`：10年度分の元データ・公式URL・脚注・CSP/スクリプト互換性をチェック。
- `tests/pm-archive-ui.test.mjs`：擬似DOMで年度/大問を選んだときの公式PDFリンクと学習履歴保存を検証。

## 正確な到達点
- **試験問題本文の新規転記や解答欄の設問別分割は行っていない。** 選択した「問」は学習記録単位であり、公式PDFは午後Ⅰまたは午後Ⅱの全問を収録した**共通冊子**である。
- 2025年度だけ元の学習アプリで使用していた開始ページ（午後Ⅰ 6/12/18、午後Ⅱ 7/20）を参考にリンクへ `#page=N` を付ける。他年度の問題ごとの開始ページは未検証なので勝手に設定しない。
- 原本PDFはIPAのサイトから別タブで開く。Webアプリ内iframeのために `frame-src` を緩和していない。IPAサイトの可用性、PDFビューア機能はブラウザー・通信状態に依存する。
- **2025年度の午後5大問は既存学習画面と年度別PDF画面の両方から選べる（追加の別問題ではない）。** 過去9回分45大問が今回新たな選択対象となる。
- 規約等についてIPA公開の「過去問題」（https://www.ipa.go.jp/shiken/mondai-kaiotu/）の説明に従い、資料の出典を示す。問題本文の再配布を増やさずリンク方式を採る。
