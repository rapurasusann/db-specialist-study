# 2025年度DB午前Ⅱ：解答解説と解答選択リセット

## 今回の仕様

- 午前Ⅱ・問1〜25のすべてについて、「答えを見る」内に正答の理由を説明する独自解説を表示する
- 正答記号はIPAの「2025年度秋期 午前Ⅱ 解答例」と一致させる
- 問題文・選択肢・画像は既存データを変更しない
- 「解答・理解度」のラジオボタンは**問題を表示するたびに未選択**へ戻す
- 選択肢をクリックして答えを選んだ後、同じ表示のまま「解答を判定」すれば判定できる
- 同じ問題を別画面に移動してから開き直す・次の問題から戻る・ページを再読み込みする場合、未選択へ戻る
- 「答えを見る」「理解度変更」などで `renderAnswer()` だけが再実行されるときは、今開いている問題の選択を勝手に消さない
- 選択内容は `sessionSelected` の一時変数だけに持ち、**新たに `progress.selected` に書き込まない**
- 過去に保存された `progress.selected` は読み出し・表示しない（バックアップの旧データは勝手に消さない）
- 正誤結果、理解度、解答回数、記述解答、原本開始ページ、バックアップ、復元は従来どおり保存する
- 問題文側の選択肢除外（取り消し線）は別機能で、再表示時リセットの仕様を維持

## 実装箇所

- `src/am2-2025-explanations.js`: 25問の解説辞書。将来の年度は同じ `transcribed[year:course:number].explanation` で拡張できる
- `index.html`: 一時的な解答変数、再表示時のリセット、ラジオボタンと採点参照の切替、解説ファイル読み込み、更新されたCSPハッシュ
- `tests/am2-answers-and-reset.test.js`: 全25問の説明・IPA解答記号の照合、未選択リセット、保存しないこと、CSPハッシュの回帰検査
