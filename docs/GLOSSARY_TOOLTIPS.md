# 過去問共通用語ツールチップ

## 用語を追加する方法

`src/glossary-terms.js` の `window.DBStudyGlossaryTerms` 配列に以下の項目を追加します。

```js
{ id: 'unique-term-id', term: '説明したい単語', definition: '短く正確な概要。', aliases: ['別表記'] }
```

- `id`: 辞書内で一意の識別子
- `term`: 問題文中で完全一致させる日本語表記
- `definition`: ホバー、キーボードフォーカス、タップで表示する説明
- `aliases`: 任意。別表記も同じ説明にする
- 長い語句を優先して一致させる（例：「プロパティグラフ」は「グラフ」より優先）
- 辞書登録後、2025年に限らず今後の年度・資格で同じ `#questionText` を使用する場合に再利用可能
- HTMLとして解釈せず、`textContent` で挿入するため、説明文にタグを含めても実行されない
- 学習履歴・出題内容・正答情報・CSV／JSONインポートは変更しない

## 操作

- PC：下線付きの用語にマウスを合わせる
- キーボード：Tabで用語に移動する
- スマホ：用語をタップする
- 閉じる：用語以外の場所をタップ／クリック、Esc、スクロール、画面サイズの変化
- 用語の色・下線は `src/glossary.js` のCSSで管理
