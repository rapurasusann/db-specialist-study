# 学習品質改善：固定完了条件
基準 main 7f66224fcd02ffed347bbb5bcf9588917d9a10f0。CS-03と独立。IPA DB Ver.4.1 https://www.ipa.go.jp/shiken/syllabus/nq6ept00000014bm-att/syllabus_db_ver4_1.pdf （現行制度限定）。新制度対応、UI刷新、同期変更は対象外。
## 固定工程（10件）
L-01 公式18小項目に対し、既存または追加教材の具体的IDを最低1件対応付ける。これは分野の最低カバーであり全知識の習得保証ではない。
L-02 2016–2025午前Ⅱの既存対象について問題・選択肢・正解・根拠の欠損と明確な誤りを修正。公式解答未照合は未確認と明記。
L-03 用語集・用語理解の既存項目を優先。L-01で不足する用語のみ補う。
L-04 Lv1–5の既存機能を維持。各段階で解答・解説を確認。不足分野はL-01と共通で補う。
L-05 明確な誤答、誤解を招く説明、根拠欠損のみ修正。既存の適切な説明は改稿しない。
L-06 網羅率：学習済みの一意ID数 / 出題可能な一意ID数。0件時は0または対象なし。試験範囲カバー率と区別。
L-07 定着率：既存の教材別習得判定を明示し、習得済み数/全対象数、0件・重複・誤答時の挙動を確認。自己評価と自動判定を区別。
L-08 苦手出題：誤答・未学習・未定着を優先、同一セッションで重複しない、対象ゼロ時に案内。
L-09 既存画面の主要学習操作をPC/スマホで確認、重大な阻害のみ修正。実機未確認は保留。
L-10 差分限定確認、重大不具合ゼロ、未実施試験を明記。公開は別判断。
