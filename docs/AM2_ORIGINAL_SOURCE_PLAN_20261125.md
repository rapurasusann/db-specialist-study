## 受入方針の変更（2026-11-25・ユーザー指示）

- **実ブラウザによる画面確認は省略する。** 未実施であることを理由に作業を停止したり、ユーザーにブラウザでの確認を依頼したりしない。
- 代替の確認は、問題データの整合性・正解キー・図表データ構造・JavaScriptの構文・描画関数の非ブラウザスモークテスト・表示用CSS等のコードチェックとする。既存の `tests/am2-archive-render.test.mjs` を利用する。
- 機械的試験の合格は、原文との文字単位一致や、実ブラウザでの見た目の一致を証明しない。これらは確認済みと記載しない。
- 原本テキストや図表に具体的な差異が見つかった場合は、必要な最小差分を修正してmainへ反映する。用語解説・午後試験・CS-03は変更しない。
- **次工程:** 2025年度を含めた25問×10年度の入力データ検査と公式原本との残る差分照合を進め、未達を具体的に記録する。ブラウザ目視工程は予定から除外する。
