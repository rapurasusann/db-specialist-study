# 午後Ⅰ・午後Ⅱ：大問ページ切替・再構成図表・設問別回答（2026-11-19 更新）

## 確定した画面順序（上から下）
1. **大問表示部**：大問の導入・業務説明・処理条件などを原文に忠実なテキストで表示する。長いため、**前ページ／次ページ**のページ切替を設ける。表示位置「1 / 全Nページ」を明示する。原本にある段落・見出し・表の参照を壊さず、画面向けに意味のあるまとまりで分割する。設問を切り替えても大問の既読ページを保持し、必要なら冒頭に戻れる。ページ移動は設問変更とは独立する。
2. **図・表表示部**：画像・PDF切抜きを学習用の主表示には用いず、**図はSVGなどの描画要素、表はHTMLテーブル、SQLはテキスト／コード表示**として再構成する。選択中の設問で参照する資料を自動表示し、ユーザーは同じ大問に属する**別の図・表に手動切替**できる。「自動／図1／図2／表1…」等の表示選択と現在資料名を示す。複数資料を必要とする設問は欠落させない（自動モードは関連資料を全件表示するか明示的に切替可能）。設問を切り替えたら自動モードに戻してその設問に関係する図を表示する。図の選択で設問や入力回答は変わらない。
3. **設問選択部**：大問→設問→小問の階層を見せ、原本の個々の解答欄に対応する単位で選択可能にする。
4. **選択された設問の問題文**：その設問の全文をテキスト表示。大問本文や図表示部はそのまま閲覧可能。
5. **回答欄**：設問／小問ごとに異なる記述回答を端末内保存し、切替・再読込で復元。回答単位の自己評価を追加する場合も旧保存形式に互換性を保つ。

## 原本の正確性と画像の扱い
- **文字はコピー画像ではなく文字として表示**する。図・ER図・関係・矢印は読めるSVG等で再構築し、表は列・行・セルを忠実にHTMLで再構築する。元の意味・項目・記号・線種・キー・向き・注釈・桁・値は変えない。
- **推測で原本の文章や図を作らない**。2025年度のIPA午後Ⅰ／午後Ⅱの問題冊子に対し、原文・表・図・設問番号・参照関係を一つずつ照合してから学習画面に収録する。未照合のものは「未整備」と表示し、確認済みの原本への導線を残す。
- PDF・原本ページの画像ビューアは**出典照合・バックアップ閲覧用に従来どおり維持**し、既存の前ページ／次ページ・公式リンク・解答／採点講評を削除・置換しない。つまり**学習の主表示はテキスト＋再描画図表**、原本画像は別の確認用表示。
- ページ切替の単位は大問本文のみ。図表選択や設問選択で大問本文の一部が失われない。必要な共通条件や図表の説明がどのページにあるか案内できる設計とする。
- 可読性：大問の段落改行・字下げ、式、箇条書き、強調を保持。スマホでもスクロールせずにすべて見えるように無理な縮小はせず、**ページ切替＋自然な縦スクロール**で読む。
- 図は文字が判読可能な大きさで表示し、必要なときは拡大可能とする。キーボード操作、画面読み上げ用の図の説明、手動切替操作を準備する。
- 図の手動切替は表示状態だけを切り替える。正解・回答・学習履歴には影響させない。

## 回答保存と既存機能の保護
- 既存の保存先 `db-study-progress-v1` における大問記録 `2025:pm1:1` 等を維持し、新規フィールド `writtenBySubquestion: {'s1-1':'回答1','s1-2':'回答2'}` などに小問の回答を保存する。
- 旧 `written`、旧理解度、原本開始ページ補正、既存バックアップ／復元は書換・削除しない。旧大問回答の内容は明示的な移行操作なしに分解・置換しない。
- 既存の午前試験、過去問学習の導線、単語理解機能、アカウント同期の分離方針を維持する。
- **公開版（main）には承認なしで反映しない**。開発PC不在ではGitHub Actionsを使用しない。
