# 2025年度DB午前Ⅱ：図表の原本切り出しと選択肢シャッフル

## 選択肢の並び替え

- 午前Ⅱの問題を開くたび、ア・イ・ウ・エの**表示位置**をFisher–Yatesでランダム化する。
- 重要：IPA公式問題・正答の記号自体は変更しない。「ア」の内容と記号「ア」は常に一致する（原本画像・正答記号との食い違いを回避）。
- 問題文側と下の解答用ラジオボタンを同じ順序で表示する。
- 「答えを見る」、解答を選ぶなど同じ問題の再描画では順番を変えず、別問題へ移動・戻る・学習画面の再表示時に改めてシャッフルする。
- 選択肢の一時除外は元の記号で追跡する。除外状態・選択状態・表示順は再表示時リセットし、学習履歴には保存しない。
- 正答・正誤判定・解説・公式画像に使う記号は常にIPA公式のア〜エのまま。

## 図表の切り出し（公式原本と同一）

既存 `pages/am2_qs_NN.webp` 画像を再利用する。図表を描き直さず、SVGの viewBox で必要部分のみ切り出す。新しい画像ファイルの生成・アップロードは不要。

対象：
- 問3：UMLの商品・倉庫関係図
- 問6：受注データの表（10行）
- 問8：SQL表定義と初期データ
- 問9：名簿の表とSQL
- 問11：注文・注文明細の主キー／外部キー図
- 問12：トランザクションのチェックポイント図
- 問23：RAID6のディスク配置図とパリティ式

問7の表は設問の**解答選択肢そのもの**なので、順序を入れ替えた画面と元のア〜エ表が混在しないよう、図の切り出し対象からは外す。ほかの問題についても、選択肢ではなく問題資料となる図表を優先する。

- 元の問題画像ビューアはそのまま残し、図・表の読み違いがあればすぐ原本と比較可能
- 利用するファイルはすべて同一サイト内で、外部通信や新しい権限は増やさない
- 既存の図をすべて画像で再利用するので、図形や数値を手作業で再描画することによる差異がない
- CSS・SVGのレイアウトは実ブラウザのPC・スマホで確認すること
